# 송현학당 · 우리 반 온라인 학당

청도학당을 학급용으로 바꾼 버전이에요. 같은 Firebase 프로젝트(unseo-hakdang)를 쓰지만,
기록은 `songhyeon/` 칸에 따로 저장돼서 청도학당 친구들 기록과 섞이지 않아요.

## 처음 한 번만 하는 준비
1. **GitHub에 새 저장소 만들기** (예: `songhyeon-hakdang`) → 이 폴더의 파일을 모두 올려요.
2. **Vercel에서 새 프로젝트로 가져오기** → 새 주소가 생겨요. (청도학당 주소와 따로예요)
3. **Firebase 규칙 붙여 넣기**
   Firebase 콘솔 → Realtime Database → 규칙 탭에 `database.rules.json` 내용을 통째로 붙여 넣고 **게시**.
   (이 규칙 안에 청도학당 규칙도 같이 들어 있어서, 청도학당도 그대로 잘 돌아가요.)

## 들어오기 · 선생님 암호
- 학생은 **암호 없이** 링크만 열면 들어와요. 처음 한 번 닉네임과 캐릭터를 정하면 다음부터는 바로 들어와요.
- 다른 폰·브라우저에서는 같은 닉네임을 적으면 예전 캐릭터를 불러와요.
- 선생님은 설정 → 연결 → **선생님 모드**에 `happy_life`를 넣으면 🧑‍🏫 선생님 화면이 열려요.
- 암호를 바꾸려면 Firebase 규칙(`database.rules.json`)의 `happy_life`를 바꾸고 다시 게시하면 돼요.

- 학생별 오늘 출석, 이번 달 출석일, 이번 주·누적 공부 시간, 독후감 수 · 📥 엑셀 표
- 칠판 글씨 바꾸기, 강의실 이름 바꾸기
- 기숙사 채팅: 항상 / 정한 시간에만 / 닫기
- 학당 입장 시간: 밤에 문 닫기
- 친구 부르기 창에서 학생 내보내기 (잠깐 내보내는 것이라 학생은 다시 들어올 수 있어요)
선생님은 채팅·입장 제한을 받지 않아요.
