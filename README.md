# 송현학당 · 우리 반 온라인 학당

운서학당을 학급용으로 바꾼 버전이에요. 같은 Firebase 프로젝트(unseo-hakdang)를 쓰지만,
기록은 `songhyeon/` 칸에 따로 저장돼서 운서학당 친구들 기록과 섞이지 않아요.

## 처음 한 번만 하는 준비
1. **GitHub에 새 저장소 만들기** (예: `songhyeon-hakdang`) → 이 폴더의 파일을 모두 올려요.
2. **Vercel에서 새 프로젝트로 가져오기** → 새 주소가 생겨요. (운서학당 주소와 따로예요)
3. **Firebase 규칙 붙여 넣기**
   Firebase 콘솔 → Realtime Database → 규칙 탭에 `database.rules.json` 내용을 통째로 붙여 넣고 **게시**.
   (이 규칙 안에 운서학당 규칙도 같이 들어 있어서, 운서학당도 그대로 잘 돌아가요.)
