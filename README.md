# 상담 신청 (학생용 페이지)

학생이 휴대폰으로 상담 시간을 고르고 신청하면, 선생님이 프로그램에서 승인·거절하는 기능입니다. 학생 정보는 **선생님 본인의 구글 시트**에만 저장됩니다.

## 구성 (3가지)
| 파일 | 역할 | 어디에 두나 |
|---|---|---|
| `index.html` (이 폴더) | 학생이 보는 신청 페이지 | GitHub Pages 등에 올림 |
| `gyomu-reserve.gs` | 신청을 받아 시트에 저장하는 구글 스크립트 | 선생님 구글 시트의 Apps Script |
| 교무실 도우미 프로그램 | 시간 만들기, 승인·거절 | 선생님 PC·패드 |

학생 페이지는 주소만 알면 열리는 공개 페이지이고, 신청 내용은 스크립트가 만든 선생님 시트로만 갑니다. 선생님이 쓰던 동기화 시트(`gyomu-sync-sheet.gs`)와는 **별개로 새 시트**를 쓰는 것을 권합니다.

## 설정 순서
### 1. 구글 시트와 스크립트
1. 새 구글 시트를 만들고 `확장 프로그램` → `Apps Script`를 엽니다.
2. `gyomu-reserve.gs` 내용을 모두 붙여넣습니다.
3. 맨 위 `ADMIN_TOKEN`을 **나만 아는 관리 암호**로 바꾸고 저장합니다. (학생에게 알려 주지 마세요. 학생 PIN 보호에도 쓰이므로 나중에 바꾸면 학생들의 기존 PIN이 맞지 않게 됩니다.)
4. `배포` → `새 배포` → 유형 `웹 앱`, 실행 계정 `나`, 액세스 `모든 사용자`로 배포하고 권한을 허용합니다.
5. 나온 웹 앱 주소(끝이 `/exec`)를 복사합니다.
- 스크립트를 고친 뒤에는 `배포 관리 → 수정 → 새 버전`으로 다시 배포해야 반영됩니다.

### 2. 학생 페이지 올리기
1. 이 폴더의 `index.html`을 GitHub 저장소(Public)에 올립니다. 교무실 도우미와 같은 저장소를 쓴다면 `reservation/index.html`처럼 폴더를 나눠 올리세요. (Settings → Pages에서 Branch `main`)
2. 학생 페이지 주소를 메모합니다. 예: `https://아이디.github.io/저장소/reservation/`

### 3. 프로그램에 연결
1. 교무실 도우미 → `상담 관리자` 탭 → 맨 위 `상담 신청 받기`를 엽니다.
2. 웹 앱 주소, 관리 암호, 학생 페이지 주소를 입력합니다.
3. 상담 가능 날짜와 시간을 만들어 올립니다.
4. 나오는 **`학생용 링크`**를 복사해 학생에게 보냅니다. 링크 끝의 `?a=…`에 스크립트 주소가 들어 있어서 학생은 아무것도 입력하지 않아도 됩니다.

링크가 길면 `index.html`의 `API_FIXED`에 웹 앱 주소를 넣어 올려 두면 `?a=` 없이 페이지 주소만 보내도 됩니다.

## 학생이 하는 일
1. 링크를 열면 가장 가까운 상담 가능일이 선택되어 시간 목록이 바로 보입니다.
2. 시간을 고르고 학번, 이름, 상담 내용, **본인이 정한 PIN**을 적어 신청합니다.
3. 아래 `내 신청 확인·취소`에서 학번과 PIN으로 승인 여부를 확인하거나 취소합니다.
- 다른 학생의 이름·내용은 보이지 않고, 학생 한 명이 동시에 신청할 수 있는 건수는 3건까지입니다.
- 선생님이 명단을 올려 두면 명단에 있는 학번·이름만 신청할 수 있습니다.

## 선생님이 하는 일
- 상담 관리자 탭의 `상담 신청 받기`에서 신청 목록을 새로 고치고 `승인`·`거절`합니다. 승인되면 학생 화면에 확정으로 보입니다.
- 오늘 승인된 상담은 홈 화면의 `오늘 상담` 카드에 표시되고, 승인 대기 건수도 보입니다.

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| "신청 주소가 연결되지 않았어요" | `?a=` 없는 주소로 열었습니다. 프로그램의 `학생용 링크`로 열거나 `API_FIXED`를 채우세요. |
| "시간표를 불러오지 못했어요" | 스크립트 액세스가 `모든 사용자`인지, 주소 끝이 `/exec`인지, 고친 뒤 새 버전으로 다시 배포했는지 확인하세요. |
| 달력에 날짜가 없음 | 프로그램에서 상담 시간을 만들어 올렸는지 확인하세요. |
| 관리 암호가 맞지 않음 | 프로그램에 넣은 암호가 `ADMIN_TOKEN`과 같은지 확인하세요. |

## 개인정보 안내
학번·이름·상담 내용은 선생님 구글 계정의 시트에 저장됩니다. 시트를 다른 사람에게 공유하지 말고, 학기가 끝나면 신청 시트를 지우거나 보관 정책에 맞게 정리하세요. 학교의 개인정보 지침을 따르세요.
